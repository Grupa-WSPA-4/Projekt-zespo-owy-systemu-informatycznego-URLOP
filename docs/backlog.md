# Backlog Produktu — System URLOPY

Ten dokument odzwierciedla strukturę **Backlogu produktu** utworzonego w usłudze **GitHub Projects** dla systemu zarządzania urlopami.

## Struktura Backlogu (MoSCoW)

###  Must Have (Priorytet najwyższy — MVP)
- **US-01:** Podgląd salda i historii urlopów (FR-02, FR-15)
- **US-02:** Przegląd kalendarza nieobecności zespołu (FR-10)
- **US-03:** Składanie wniosku urlopowego ze wskazaniem zastępcy (FR-03, FR-04, FR-05)
- **US-04:** Zatwierdzanie / odrzucanie wniosków przez przełożonego (FR-07, FR-08, FR-09)
- **US-05:** Obsługa urlopu na żądanie w trybie natychmiastowym (FR-11)
- **US-06:** Anulowanie zatwierdzonego wniosku urlopowego (FR-12)
- **US-07:** Zarządzanie kontami i rocznymi limitami przez administratora (FR-13, FR-14)

###  Should Have (Ważne, ale niekrytyczne na start)
- **US-08:** Generowanie zaawansowanych raportów nieobecności dla kadr (FR-15)
